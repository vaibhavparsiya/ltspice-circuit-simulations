The common emitter (CE) configuration is the most widely used BJT circuit setup because it provides high voltage, current, and power gains, making it ideal for signal amplification. In this configuration, the input signal is applied between the base and the emitter, while the output is taken across the collector and the emitter, making the emitter terminal common to both sides. A defining characteristic of the CE amplifier is its 180-degree phase inversion, meaning an increase in input voltage results in a amplified decrease in output voltage. It features moderate input impedance and high output impedance, and its current amplification factor is denoted by Beta (β), which typically ranges from 20 to several hundred.
